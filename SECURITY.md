# Security

This repository implements white-box adversarial attacks for **authorized robustness evaluation** of ASR models.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/hammaad2002/ASRAdversarialAttacks/security/advisories/new) rather than a public issue if you believe the library itself has a security defect (for example unsafe deserialization or a dependency issue).

## Out of scope

Requests to attack third-party production speech systems, harvest credentials, or bypass access controls will be ignored.
